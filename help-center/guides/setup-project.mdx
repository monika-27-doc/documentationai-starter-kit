---
title: Run your first worker
description: Start a Node.js worker that picks up jobs from the default queue.
---

A worker is a long-running process that takes jobs from a queue and runs them.

```javascript
import { Kestrel } from "@kestrel/sdk";

const kestrel = new Kestrel(process.env.KESTREL_API_KEY);

kestrel.worker("default", {
  "send-welcome-email": async ({ payload }) => {
    await sendWelcomeEmail(payload.userId);
  },
});
```

Run it with `node worker.js`. Throwing an error marks the attempt as failed, and Kestrel retries it. See [Retries and failures](/guides/retries).
