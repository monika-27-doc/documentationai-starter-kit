---
title: Quickstart
description: Create an API key, install an SDK and queue your first background job in about five minutes.
---

Kestrel runs your background work: emails, exports, webhooks, anything that shouldn't block a request. This guide takes you from a new account to a finished job.

<Callout kind="info" collapsed="false">
  You need a Kestrel account. The Free plan includes 10,000 requests a day, which is plenty for this guide.
</Callout>

<Steps>
  <Step title="Create an API key" icon="key" title-type="p">
    In the Kestrel app, go to **Settings > API keys** and click **Create key**. Choose the **Test** environment and copy the key. It starts with `kst_test_`.

    ```bash
    export KESTREL_API_KEY="kst_test_..."
    ```
  </Step>

  <Step title="Install an SDK" icon="package" title-type="p">
    Kestrel has official SDKs for Node.js, Python and Go. You can also call the REST API directly.

    <Tabs>
      <Tab title="Node.js" icon="hexagon">
        ```bash
        npm install @kestrel/sdk
        ```
      </Tab>

      <Tab title="Python" icon="file-code">
        ```bash
        pip install kestrel-sdk
        ```
      </Tab>

      <Tab title="Go" icon="box">
        ```bash
        go get github.com/kestrel-run/kestrel-go
        ```
      </Tab>
    </Tabs>
  </Step>

  <Step title="Queue your first job" icon="send" title-type="p">
    A job has a `type` your workers know how to handle and a JSON `payload`. Kestrel returns the job straight away with the status `queued`.

    <CodeGroup tabs="cURL,Node.js,Python,Go">
    ```bash
    curl https://api.kestrel.dev/v1/jobs \
      -H "Authorization: Bearer $KESTREL_API_KEY" \
      -H "Content-Type: application/json" \
      -d '{"type": "send-welcome-email",
           "payload": {"userId": "usr_8f2k"}}'
    ```

    ```javascript
    import { Kestrel } from "@kestrel/sdk";

    const kestrel = new Kestrel(process.env.KESTREL_API_KEY);

    const job = await kestrel.jobs.create({
      type: "send-welcome-email",
      payload: { userId: "usr_8f2k" },
    });
    ```

    ```python
    from kestrel import Kestrel

    kestrel = Kestrel(os.environ["KESTREL_API_KEY"])

    job = kestrel.jobs.create(
        type="send-welcome-email",
        payload={"userId": "usr_8f2k"},
    )
    ```

    ```go
    client := kestrel.New(os.Getenv("KESTREL_API_KEY"))

    job, err := client.Jobs.Create(ctx, kestrel.JobParams{
        Type:    "send-welcome-email",
        Payload: map[string]any{"userId": "usr_8f2k"},
    })
    ```
    </CodeGroup>
  </Step>

  <Step title="Check the result" icon="circle-check" title-type="p">
    Open **Jobs** in the app to watch it run, or fetch it by ID. A finished job has the status `succeeded` and a `completedAt` time.

    ```bash
    curl https://api.kestrel.dev/v1/jobs/job_3hd92k \
      -H "Authorization: Bearer $KESTREL_API_KEY"
    ```
  </Step>
</Steps>
